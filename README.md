# Winter Arc

A personal daily-goals app for a 90-day challenge: daily tasks with photo
proof, postpone instead of fail, streaks, a rewards spin wheel, and an
end-of-challenge recap video — all stored locally in the browser.

## Files
`index.html`, `style.css`, `app.js`, `manifest.json`, `service-worker.js`
— all in the same folder.

## Run it
Open `index.html` in a browser, or host on GitHub Pages.

## First use
Set a username/password and your start date — this unlocks the app going
forward and generates all 90 days of goals automatically.
